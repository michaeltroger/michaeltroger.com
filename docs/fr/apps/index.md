* Adidas Training — plus de 10 millions de téléchargements ; anciennement Runtastic Results, arrêtée ; améliorations fonctionnelles.
* Adidas Shopping — plus de 50 millions de téléchargements ; améliorations fonctionnelles.
* Adidas Confirmed — plus de 10 millions de téléchargements ; améliorations fonctionnelles.
* Runtastic Steps — plus d’un million de téléchargements ; anciennement Runtastic Me, arrêtée ; améliorations fonctionnelles.
* Runtastic Sleep Better — plus de 5 millions de téléchargements ; arrêtée ; maintenance.
* Runtastic Heart Rate Monitor — plus de 5 millions de téléchargements ; arrêtée ; maintenance.
