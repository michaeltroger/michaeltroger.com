# {{ site.data.apps.pdfwallet }}
Anteriormente conhecida como Green Pass PDF Wallet, esta aplicação para iOS, macOS e Android guarda e apresenta documentos PDF importantes, como bilhetes de transportes públicos ou de teatro. Os códigos de barras, incluindo códigos QR, são ampliados automaticamente.

Os PDFs ficam guardados na própria aplicação, como numa carteira, e são fáceis de encontrar. A aplicação também deteta e amplia códigos de barras sem ser necessário aumentar o zoom manualmente.
